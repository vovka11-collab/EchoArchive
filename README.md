# EchoArchive

> Стильный, современный мобильный клиент и плеер для прослушивания музыки, саундтреков и живых записей из бесконечной библиотеки **Archive.org**.

Проект разработан полностью на мобильном устройстве в редакторе **Spck** в рамках концепции *вайбкодинга*.

---

## 🎨 Дизайн и Интерфейс

Интерфейс приложения вдохновлен эстетикой современных стриминговых сервисов с глубокой темной темой и минималистичным визуалом:
* **Dark Mode:** Глубокие графитовые тона, снижающие нагрузку на глаза.
* **Glassmorphic UI:** Элементы интерфейса с мягким размытием заднего плана и аккуратными закруглениями.
* **Кастомный плеер:** Минималистичный пульт управления, стильный ползунок прогресса трека и обложки альбомов.
* **Адаптивность:** Полная оптимизация под экраны смартфонов с удобной нижней навигацией.

---

## ✨ Ключевые Возможности

* 🔍 **Поиск по Archive.org:** Быстрый поиск альбомов, OST (аниме, игры), коллекций и отдельных треков.
* 📂 **Сортировка и Фильтры:** Удобная навигация по дате добавления и категориям.
* 🎧 **Интерактивный плеер:** Воспроизведение в реальном времени, перемотка, переключение треков, случайный порядок (shuffle) и повтор.
* 📑 **Вкладки:** Быстрый доступ через нижнее меню («Главная», «Закладки», «Настройки»).
